# Dedan Kimathi University Lost & Found Website

## Overview
This project is a simple web application to help students and staff report and recover lost items at Dedan Kimathi University.  
It is currently in the early development stage, with a basic homepage layout and styling.

## Features (so far)
- Homepage with header, navigation bar, and footer
- Section for recently found items
- Base CSS styling for body, header, navigation, main content, item cards, and footer
- Responsive navigation bar for small screens
